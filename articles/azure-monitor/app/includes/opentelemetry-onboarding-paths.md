> [!NOTE]
> For .NET, Node.js, and Python applications:
>
> * **New app or adopting OpenTelemetry for the first time:** Use the [Microsoft OpenTelemetry Distro](../opentelemetry-enable.md?tabs=aspnetcore).
> * **Already using the [Azure Monitor OpenTelemetry Distro](../opentelemetry-enable.md?tabs=aspnetcore):** No action needed.
> * **Using Application Insights .NET SDK 2.x:** [Upgrade to 3.x](../migrate-to-opentelemetry.md?tabs=dotnet) to minimize reinstrumentation, or start fresh with the [Microsoft OpenTelemetry Distro](../opentelemetry-enable.md?tabs=aspnetcore).
>
> For Java applications, use the [Azure Monitor OpenTelemetry Distro](../opentelemetry-enable.md?tabs=aspnetcore).
>
> For AI-assisted instrumentation guidance, see the [Application Insights instrumentation skill](/azure/developer/azure-skills/skills/app-insights-instrumentation). For guided setup and analysis of existing Application Insights instrumentation, see the [Azure MCP Server tools for Azure Monitor](/azure/developer/azure-mcp-server/tools/azure-monitor#instrumentation-start-orchestration).
