> [!IMPORTANT]
> Experiments (classic) is being replaced by [Chaos Studio Workspaces](../chaos-studio-workspaces-overview.md), the current resource model for Azure Chaos Studio. It's still Chaos Studio, with a new way to define and run your tests. Microsoft no longer adds features to Experiments (classic) and considers only critical fixes, such as security updates, for backport to this model. Use Workspaces for new resilience tests. To move your existing experiments, follow [Move from Experiments (classic) to Chaos Studio Workspaces](../chaos-studio-migrate-from-classic.md).
