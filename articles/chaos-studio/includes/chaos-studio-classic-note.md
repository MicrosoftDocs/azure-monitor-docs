> [!IMPORTANT]
> This article applies to the legacy Experiments (classic) resource model. Microsoft no longer develops features for Experiments (classic) and considers only critical fixes, such as security updates, for backport. For new resilience testing, use [Chaos Studio Workspaces](../chaos-studio-workspaces-overview.md), where development is active. To choose a resource model, see [Choose between Chaos Studio Workspaces and Experiments (classic)](../chaos-studio-workspaces-vs-experiments.md).
